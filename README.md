# 📍 Mouse Coordinate Tracker (Automation Helper)

**Mouse Coordinate Tracker** is a essential utility for developers building desktop automation scripts. It provides real-time X and Y coordinates of your cursor, allowing you to map out GUI interactions for **PyAutoGUI**, **Selenium**, or **AutoIt** with surgical precision.

## 🚀 Why Use This?
Mapping coordinates manually is time-consuming. This script eliminates the guesswork by displaying live coordinates directly in your terminal, so you can build robust automation pipelines in minutes.

## ✨ Key Features
* **Live Tracking:** Real-time updates as you move the mouse.
* **Low Overhead:** Zero-latency tracking with minimal CPU usage.
* **Clipboard Ready:** Easily grab X, Y values for your automation code.

## 🛠 Tech Stack
* **Language:** Python 3.12
* **Library:** PyAutoGUI / Pynput
